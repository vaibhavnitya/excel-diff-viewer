# excel-diff-viewer

An NPM library to view and diff Excel/CSV files in the browser. Built for React and Next.js.

**Status:** Early development — not yet published.

## Packages

- `@your-scope/excel-diff-core` — Parsing + diff engine (framework-agnostic)
- `@your-scope/excel-diff-react` — React hooks for custom UIs
- `@your-scope/excel-diff-ag-grid` — Drop-in components using AG Grid

