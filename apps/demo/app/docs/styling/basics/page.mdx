# Basics

Theme the viewer with `--edv-*` CSS variables, the typed `theme` prop, or
override slots via `classNames`. No CSS-in-JS runtime and no bundled design
systems. Precedence and philosophy: monorepo `DESIGN.md` → **Theming
philosophy**. For “which lever should I use?”, see the
[decision guide](/docs/styling/decision-guide).

## CSS variables

Defaults ship in `@mojro/excel-diff-ui/styles.css`. Dark values apply under
`:root[data-theme='dark']`.

**Full `--edv-*` reference** (light/dark defaults and purpose notes):
[Custom Themes](/docs/styling/custom).

```css
/* loaded after @mojro/excel-diff-ui/styles.css */
:root {
  --edv-added-bg: #dcfce7;
  --edv-removed-bg: #fee2e2;
  --edv-modified-bg: #fef3c7;
  --edv-border-radius: 6px;
}
```

## theme prop

Pass a typed `Theme` object to set `--edv-*` variables as inline styles on the
component root. Every field is optional — omit what you do not want to override.
Map MUI / Carbon / etc. tokens in your app (see [MUI](/docs/styling/mui) and
[Carbon](/docs/styling/carbon) for copy-paste adapters).

```tsx
import { ExcelViewer, type Theme } from '@mojro/excel-diff-ui';

const theme: Theme = {
  colors: {
    added: '#dcfce7',
    modified: '#fef3c7',
    removed: '#fee2e2',
    headerBg: '#f5f5f5',
  },
  typography: { fontSize: 14, headerWeight: 600 },
  spacing: { rowHeight: 36, headerHeight: 40 },
  shape: { borderRadius: 4 },
};

<ExcelViewer file={file} height={600} theme={theme} />
```

Precedence (low → high): stylesheet defaults → dark mode → consumer CSS →
`theme` → `classNames` → `style`. `spacing.rowHeight` / `headerHeight` also feed
AG Grid; explicit `agGridProps.rowHeight` still wins.

## classNames prop

Override named slots without fighting the default stylesheet:

```tsx
<ExcelViewer
  file={file}
  height={600}
  classNames={{
    root: 'my-viewer',
    toolbar: 'my-toolbar',
    addedCell: 'bg-emerald-100',
    removedCell: 'bg-rose-100',
    modifiedCell: 'bg-amber-100',
  }}
/>
```

Slots: `root`, `toolbar`, `grid`, `sheetTabs`, `error`, `loading`, `addedCell`,
`removedCell`, `modifiedCell`, `addedRow`, `removedRow`, `modifiedRow`,
`keyColumn`.

## Dark mode

Built-in dark tokens activate when `data-theme="dark"` is set on `:root`. This
demo also toggles the `.dark` class via `next-themes` and syncs `data-theme` for
the UI package. Remember: a `theme` prop’s inline variables outrank dark-mode
CSS — align tokens with the host mode or leave them unset.
