# Styling

The UI package ships static CSS. Theme with CSS variables, the typed `theme`
prop, or slot overrides via `classNames`. There is **no CSS-in-JS runtime** and
**no bundled design system**.

Authoritative detail — precedence, adapter pattern, and when to use each lever —
lives in the monorepo `DESIGN.md` → **Theming philosophy**. This section is a
map of the guides.

## Theming layers

Precedence (lowest → highest):

1. Library defaults in `@mojro/excel-diff-ui/styles.css` (`--edv-*`)
2. Dark mode (`:root[data-theme='dark']`)
3. Your CSS targeting `--edv-*`
4. `theme` prop (inline CSS variables on the component root)
5. `classNames` prop
6. `style` prop

## No bundled design systems

`@mojro/excel-diff-ui` never imports MUI, Carbon, Tailwind, or similar. Map your
design tokens to the EDV `Theme` shape in **your** app. The demo ships
copy-paste adapter helpers under `apps/demo/examples/` — copy them; do not
import them from an npm package.
