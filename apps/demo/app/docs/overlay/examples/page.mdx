# Overlay examples

## 1. Flat fuel surcharge

Synthetic lanes + `percentIncrease` on `Fuel Pct`.

```ts
compose: {
  kind: 'rules',
  rules: [{
    op: 'percentIncrease',
    base: 'Base Rate',
    overlay: 'Fuel Pct',
    target: 'Effective Rate',
    defaultWhenMissing: 0,
  }],
}
```

## 3. Real-shaped rate card + surcharge template

`fn` compose joins on `Vehicle Type` and attaches surcharge-derived columns.
