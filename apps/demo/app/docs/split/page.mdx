# Split

`<ExcelSplitViewer>` shows before and after side by side with rows aligned on shared keys and ghost rows for gaps. Prefer it when you want visual inspection without unified color highlighting. Use `agGridProps` for AG Grid filtering and other features (sorting stays off by default so panes stay aligned) — see [Filtering & sorting](/docs/filtering-and-sorting).

## When to pick split over diff

- Reviewers want Excel-like left/right comparison
- You care about row alignment more than a single unified change list
- Diff colors are noisy for your audience

Use `<ExcelDiffViewer>` when you want one grid with added / removed / modified status and cell-level change highlighting.

## Minimal usage

```tsx
import { ExcelSplitViewer } from '@mojro/excel-diff-ui';

<ExcelSplitViewer
  fileA={fileA}
  fileB={fileB}
  schema={schema}
  height={600}
  labelA="Before"
  labelB="After"
/>
```
