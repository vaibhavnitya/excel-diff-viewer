# Viewer

`<ExcelViewer>` parses a single Excel or CSV file in a Worker and renders it as a searchable, sortable AG Grid with sheet tabs. Pass `agGridProps` for filtering, sidebars, pagination, and other AG Grid features — see [Filtering & sorting](/docs/filtering-and-sorting).

## Minimal usage

```tsx
import { ExcelViewer } from '@mojro/excel-diff-ui';
import '@mojro/excel-diff-ui/styles.css';

<ExcelViewer file={file} height={600} />
```

## Examples

### Basic

```tsx
const [file, setFile] = useState<File | null>(null);

<input type="file" onChange={(e) => setFile(e.target.files?.[0] ?? null)} />
<ExcelViewer file={file} height={600} />
```

### Sheet selection

```tsx
<ExcelViewer
  file={file}
  height={600}
  defaultSheet="Rates"
  onSheetChange={(name) => console.log('sheet', name)}
/>
```

### Error handling

```tsx
<ExcelViewer
  file={file}
  height={600}
  onError={(error) => analytics.capture('excel_error', { code: error.code })}
  renderError={(error) => (
    <div role="alert">
      {error.code}: {error.message}
    </div>
  )}
/>
```

## Common pitfalls

- **Height** — pass `height` or give the parent an explicit height. Unsized parents look broken.
- **File lifecycle** — the hook terminates its Worker on unmount. Avoid keeping stale `File` references across navigations if you also clear component state.
- **CSS** — forget the `styles.css` import and theming / layout will look unstyled.

<Callout type="warn">
  `file` accepts `File | ArrayBuffer | null`. Passing a parsed `Workbook` object
  is not supported — use the hooks or core APIs if you already have a workbook.
</Callout>
