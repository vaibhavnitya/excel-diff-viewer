# Getting started

Install the packages, import the CSS once, and render a viewer or diff in a few lines.

## Install

npm:

```bash
npm install @mojro/excel-diff-ui @mojro/excel-diff-react @mojro/excel-diff-core react react-dom ag-grid-community ag-grid-react
```

yarn:

```bash
yarn add @mojro/excel-diff-ui @mojro/excel-diff-react @mojro/excel-diff-core react react-dom ag-grid-community ag-grid-react
```

pnpm:

```bash
pnpm add @mojro/excel-diff-ui @mojro/excel-diff-react @mojro/excel-diff-core react react-dom ag-grid-community ag-grid-react
```

## Peer dependencies

- **React 18+** (`react`, `react-dom`)
- **AG Grid Community** (`ag-grid-community`, `ag-grid-react`) — required by `@mojro/excel-diff-ui` only

If you only need the engine or hooks, install `core` / `react` without AG Grid.

## CSS import

```tsx
import '@mojro/excel-diff-ui/styles.css';
```

Also import AG Grid theme CSS once in your app (see the demo root layout for a working example).

## Theming (brief)

The UI package is design-system-agnostic: override `--edv-*` CSS variables, pass
a typed `theme` prop, or map MUI / Carbon tokens with a consumer adapter.
Details: [Styling](/docs/styling) and the
[decision guide](/docs/styling/decision-guide). Philosophy:
monorepo `DESIGN.md`.

## Hello world — viewer

```tsx
'use client';

import { useState } from 'react';
import { ExcelViewer } from '@mojro/excel-diff-ui';
import '@mojro/excel-diff-ui/styles.css';

export function App() {
  const [file, setFile] = useState<File | null>(null);
  return (
    <>
      <input type="file" onChange={(e) => setFile(e.target.files?.[0] ?? null)} />
      <ExcelViewer file={file} height={600} />
    </>
  );
}
```

## Minimal diff

```tsx
'use client';

import { ExcelDiffViewer } from '@mojro/excel-diff-ui';

const schema = {
  keyFields: ['origin', 'destination', 'mode'],
  optionalKeyFields: ['destination'],
  valueFields: ['rate'],
};

export function DiffApp({ fileA, fileB }: { fileA: File | null; fileB: File | null }) {
  return (
    <ExcelDiffViewer
      fileA={fileA}
      fileB={fileB}
      schema={schema}
      height={600}
    />
  );
}
```

## Next.js notes

- Import the UI CSS (and AG Grid CSS) from the **root layout**, not from every page.
- Components that take `File` state are **Client Components** (`'use client'`).
- The Worker loads via a **Blob URL** embedded in core — no custom webpack Worker loader or `new URL(..., import.meta.url)` config is required.
- Add the packages to `transpilePackages` in `next.config`:

```js
transpilePackages: [
  '@mojro/excel-diff-core',
  '@mojro/excel-diff-react',
  '@mojro/excel-diff-ui',
],
```

<Callout type="tip">
  Prefer an explicit `height` (or a sized parent). The grid fills its parent by
  default; unsized parents collapse to a small minimum.
</Callout>
