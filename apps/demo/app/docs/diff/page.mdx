# Diff

`<ExcelDiffViewer>` compares two files by business key, highlights added / removed / modified cells, and can export the result as CSV. Column filters and sorting come from AG Grid via `agGridProps` — see [Filtering & sorting](/docs/filtering-and-sorting).

## Minimal usage

```tsx
import { ExcelDiffViewer } from '@mojro/excel-diff-ui';

const schema = {
  keyFields: ['origin', 'destination', 'mode'],
  optionalKeyFields: ['destination'],
  valueFields: ['rate'],
};

<ExcelDiffViewer
  fileA={fileA}
  fileB={fileB}
  schema={schema}
  height={600}
/>
```

## Schema configuration

### Sample schema example

```ts
const sampleSchema = {
  keyFields: ['origin', 'destination', 'mode'],
  // Blank destination means “any destination” as its own bucket (*)
  optionalKeyFields: ['destination'],
  valueFields: ['rate'],
  numericTolerance: { absolute: 0.01, relative: 1e-9 },
};
```

### Infer vs hand-write

```ts
import { inferSchema } from '@mojro/excel-diff-core';

const inferred = inferSchema(headers);
if (inferred.ok) {
  // Good starting point for well-named columns
  setSchema(inferred.value);
}
```

Hand-write when inference misses your keys, when optional wildcards matter, or when value fields should be a subset of columns.

See [Core concepts](/docs/core-concepts) for key / optional / tolerance details.

## CSV export

The toolbar can include an export button (`enableCSVExport`). For your own UI, use the utility:

```tsx
import { diffToCSV } from '@mojro/excel-diff-ui';

function ExportButton({ diff }: { diff: DiffResult }) {
  return (
    <button
      type="button"
      onClick={() => {
        const csv = diffToCSV(diff);
        const blob = new Blob([csv], { type: 'text/csv' });
        const url = URL.createObjectURL(blob);
        const a = document.createElement('a');
        a.href = url;
        a.download = 'diff.csv';
        a.click();
        URL.revokeObjectURL(url);
      }}
    >
      Download CSV
    </button>
  );
}
```

## Styling / Theme

Diff status colors come from `--edv-added-*` / `--edv-removed-*` / `--edv-modified-*` (or the `theme` prop). See [Styling basics](/docs/styling/basics), [MUI](/docs/styling/mui), and [Carbon](/docs/styling/carbon).

## Common patterns

- **Schema changes** — updating `schema` cancels in-flight work and re-diffs (latest-wins).
- **showOnlyChanges** — hide unchanged rows when reviewing large sheets.
- **search** — use controlled `searchQuery` / `onSearchQueryChange` to sync with your chrome.
